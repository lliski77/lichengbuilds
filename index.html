01 About the maker

Curiosity,
wired into motion.

I’m Licheng, a student maker from Philadelphia exploring the space where hardware meets imagination. I like projects that respond, move, glow, and make people want to reach out and try them.

My work moves between embedded systems and computer vision—from games compressed onto tiny displays to real-time hand tracking that turns gestures into light. Each build is a chance to learn one layer deeper: electronics, code, interaction, and the patience to make them work together.

01OLED / INTERACTION
EXPERIMENT 01 / 05

Animated Eyes
+ Pocket Pong

A tiny screen with two personalities: expressive robot eyes and a classic arcade game.

Built around an ESP32 and a 0.96-inch OLED, this interface brings animated eyes to life through button controls. One press switches the system into a playable Pong mode, where a joystick transforms the display into a pocket-sized arcade. Programmed in the Arduino IDE to explore responsive graphics, input handling, and playful interaction on minimal hardware.

ESP32OLEDArduino IDEJoystick
02LCD / MUSIC
EXPERIMENT 02 / 05

I Saw Your Face
Lyric Display

Turning a 16×2 character display into a perfectly timed visual companion for music.

An Arduino Uno drives a 16×2 LCD through synchronized lines from “I Saw Your Face” by Malcolm Todd. The project treats timing as an interface challenge—sequencing each lyric so a limited character grid still feels expressive, musical, and intentional.

Arduino Uno16×2 LCDC++Timing
03LCD / GAME
EXPERIMENT 03 / 05

Dino,
Recompressed.

The browser classic, rebuilt on thirty-two characters and controlled with a joystick.

This Arduino Uno project recreates the classic Dino runner on a 16×2 LCD. A joystick controls each jump while custom characters, obstacle timing, score logic, and collision detection squeeze an entire game loop into one remarkably small display.

Arduino Uno16×2 LCDJoystickGame Logic
04OLED / TYPOGRAPHY
EXPERIMENT 04 / 05

Damned
in 0.96 Inches

A miniature kinetic-typography study synchronized to Miguel’s “Damned.”

Powered by an ESP32, this 0.96-inch OLED sequences lyrics from “Damned” by Miguel in sync with the track. The build explores how pacing, line breaks, and micro-animations can create emotion and rhythm even on a monochrome screen barely larger than a postage stamp.

05VISION / PHYSICAL OUTPUT
EXPERIMENT 05 / 05

Hand to Light,
in Real Time.

Computer vision counts a gesture; an Arduino turns that information into physical light.

OpenCV and MediaPipe track a hand through a live camera feed and count the number of raised fingers. That result is sent to an Arduino Uno, which controls the corresponding LED output in real time—connecting perception software to a tangible electronic response with almost no delay.

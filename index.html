01OLED / INTERACTION
PROJECT 01 / 05

Animated Eyes
+ Pong

Animated eyes and a playable Pong game on one small OLED screen.

I made this project with an ESP32 and a 0.96-inch OLED display. Buttons control the different eye animations, and another button switches the screen into a classic Pong game. The game is controlled with a joystick. I programmed everything in the Arduino IDE.

ESP32OLEDArduino IDEJoystick
02LCD / MUSIC
PROJECT 02 / 05

I Saw Your Face
Lyric Display

Lyrics from “I Saw Your Face” timed to the song on a 16×2 LCD.

I used an Arduino Uno and a 16×2 LCD to display lyrics from “I Saw Your Face” by Malcolm Todd. I timed each line in the code so the words change along with the song. The hardest part was getting the timing right and fitting the lyrics on such a small screen.

Arduino Uno16×2 LCDC++Timing
03LCD / GAME
PROJECT 03 / 05

LCD
Dino Game

A joystick-controlled Dino game running on a 16×2 LCD.

This is my version of the classic Dino game, made with an Arduino Uno and a 16×2 LCD. You use a joystick to make the dinosaur jump over obstacles. I added the game loop, score, collision detection, and custom LCD characters in the Arduino code.

Arduino Uno16×2 LCDJoystickGame Logic
04OLED / TYPOGRAPHY
PROJECT 04 / 05

Damned
Lyric Display

Lyrics from “Damned” by Miguel playing in sync on a small OLED.

I used an ESP32 and a 0.96-inch OLED display to show lyrics from “Damned” by Miguel. The lyrics are timed to the song, with small text animations between lines. This project helped me learn more about OLED graphics and timing with the ESP32.

ESP32OLEDArduino IDELyrics
05VISION / PHYSICAL OUTPUT
PROJECT 05 / 05

LED
Hand Tracking

My hand controls LEDs in real time based on how many fingers I hold up.

I used OpenCV and MediaPipe to track my hand through a webcam and count how many fingers are raised. Python sends that number to an Arduino Uno, which turns on the matching number of LEDs. It was a fun way to connect computer vision with a real electronics project.
